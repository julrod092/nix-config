# Emacs Keybindings

This reference covers the active Spacemacs layers and custom bindings from `/Users/julian/.nix-config/modules/home-manager/programs/emacs/default.nix`. In buffers where `SPC m` is shown, your major-mode leader `,` works as the shorter equivalent for the same command group.

## Core Concepts

These bindings provide command discovery, mode-specific commands, and the main Spacemacs command entry points.

| Name | Command | Description |
|---|---|---|
| Leader | `SPC` | Opens the main Spacemacs leader-key command tree. |
| Major-mode leader | `SPC m` or `,` | Opens commands specific to the current major mode. |
| Emacs command | `SPC SPC` | Runs an Emacs command by name with Helm. |
| Vim command | `:` | Runs an Evil ex command. |
| Universal argument | `SPC u` | Sends a prefix argument to the next command. |
| Escape | `fd` | Leaves insert state, aborts prompts, or quits transient buffers. |
| Show top-level keys | `SPC h k` | Opens which-key for top-level bindings. |
| Help | `SPC h` | Opens Spacemacs help commands. |
| Describe function | `SPC h d f` | Shows documentation for an Emacs function. |
| Describe variable | `SPC h d v` | Shows documentation for an Emacs variable. |
| Describe key | `SPC h d k` | Shows the command bound to a key sequence. |
| Describe mode | `SPC h d m` | Shows documentation for the current major and minor modes. |
| Spacemacs docs | `SPC h SPC` | Searches Spacemacs layers and documentation. |
| Vim tutor | `SPC h T v` | Opens the Evil/Vim tutorial. |
